🛒 마트가자

개인정보처리방침 · Privacy Policy

본 방침은 앱 서비스 제공자(이하 "운영자")가 마트가자 앱(Android)을 운영하면서 적용되는 개인정보 처리 방식을 설명합니다.
시행일: 2026년 05월 21일

1. 운영자가 직접 수집하는 개인정보

마트가자는 회원가입, 로그인, 소셜 로그인 기능이 없습니다.
사용자가 입력하는 쇼핑 목록·카테고리 데이터는 기기 내부에만 저장되며, 운영자 서버로 전송되거나 저장되지 않습니다.

✅ 운영자는 사용자의 개인정보를 직접 수집하지 않습니다.

2. 제3자(Google)가 수집하는 정보 — 광고

본 앱은 Google AdMob을 통해 배너 광고를 게재합니다. 광고를 제공하기 위해 Google은 아래 정보를 자동으로 수집할 수 있습니다.

수집 항목수집 주체목적
광고 식별자 (GAID)Google AdMob맞춤형 광고 제공
기기 정보 (OS 버전, 기기명)Google AdMob광고 최적화
IP 주소Google AdMob지역 기반 광고
앱 사용 패턴Google AdMob광고 노출 빈도 측정

Google의 개인정보처리방침: https://policies.google.com/privacy
광고 식별자(GAID) 재설정 또는 광고 개인화 비활성화: 기기 설정 → 개인정보 보호 → 광고에서 가능합니다.

3. 제3자(Google)가 수집하는 정보 — 앱 분석(Firebase Analytics)

본 앱은 서비스 개선을 위해 Google Firebase Analytics를 사용합니다. Firebase Analytics는 앱 사용 패턴을 익명으로 수집·분석하며, 수집된 정보는 집계·통계 형태로만 활용됩니다.

수집 항목수집 주체목적
앱 인스턴스 ID (익명)Google Firebase기기 구분 (개인 식별 불가)
기기 정보 (OS 버전, 기기 모델)Google Firebase기기 호환성 분석
국가·언어 정보Google Firebase지역별 사용 통계
앱 실행·종료, 화면 전환 이벤트Google Firebase사용 패턴 분석 및 서비스 개선
기능 사용 이벤트 (항목 추가, 카테고리 선택 등)Google Firebase주요 기능 개선 우선순위 결정

수집된 데이터는 개인을 특정할 수 없는 익명 통계로만 처리되며, 제3자에게 판매되지 않습니다.
Firebase 개인정보처리방침: https://firebase.google.com/support/privacy
데이터 수집 비활성화: 기기 설정 → Google → 광고 → 광고 개인화 비활성화 또는 기기 설정에서 '사용 및 진단 데이터 공유'를 해제하면 수집을 제한할 수 있습니다.

4. 제3자(Google Play)가 수집하는 정보 — 인앱결제

'광고 제거' 기능을 구매하는 경우 Google Play 결제 시스템을 통해 처리됩니다. 결제 정보(카드번호, 결제 내역 등)는 Google이 관리하며, 운영자는 결제 성공 여부만 전달받습니다. 운영자는 결제 정보를 저장하거나 열람하지 않습니다.

5. 인터넷 접속

앱은 광고 로드, 구매 처리, 앱 사용 통계 전송을 위해 인터넷에 접속합니다. 인터넷 없이도 쇼핑 목록 추가·체크 등 핵심 기능은 모두 오프라인으로 동작합니다. 오프라인 중 발생한 분석 이벤트는 기기에 임시 저장되었다가 네트워크 연결 시 자동으로 전송됩니다.

6. 어린이 개인정보 보호

마트가자는 만 14세 미만 어린이를 대상으로 하지 않습니다. 만 14세 미만 사용자는 보호자의 동의 하에 사용하여 주시기 바랍니다.

7. 방침 변경 안내

본 개인정보처리방침이 변경될 경우, 변경 7일 전 이 페이지를 통해 고지합니다. 중요한 변경사항은 앱 업데이트 시 팝업으로 별도 안내합니다.
